## 复现命令

从项目根目录执行后端测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s backend/tests -v
```

前端测试与构建：

```powershell
cd frontend
npm.cmd test
npm.cmd run build
```

本地服务启动后，在前端目录执行浏览器检查，需要本机 Microsoft Edge：

```powershell
node scripts/verify-ui.mjs
```

后端测试文件为 `backend/tests/test_backend.py`；浏览器检查脚本为 `frontend/scripts/verify-ui.mjs`。在执行新的界面验证前，保留需要的工程备份，避免将测试操作误作为正式谱面的编辑。

## V0.1 当时尚未验证或实现

- Demucs 模型在真实歌曲上的完整分离流程、听感、质量与性能尚未成功完成验证。演示四轨为合成数据，WAV 下载通过不等于真实模型分离通过。
- 30 首授权曲库与 5–10 首人工精标基准尚未完成，尚无可发布的和弦准确率、音符 F1、歌词误差或处理速度结论。
- AI 人声转写、TXT 自动对齐与逐字/逐词 forced alignment 尚未接入。
- 可靠的语义段落识别、精确贝斯演奏法、自动音色结论与 AI 建议 Fill 尚未达到完整规划目标。
- MIDI、MusicXML、五线谱和桌面打包属于后续版本范围。

当前验证支持“可编辑、可保存、可导出”的基础备曲流程；真实歌曲的候选结果仍需试听和人工校正。
